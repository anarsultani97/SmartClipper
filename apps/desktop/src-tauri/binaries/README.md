# Generated sidecars

Place per-target packaged Python workers and approved media executables here during builds. Binary files are ignored by Git.

Build Windows binaries on Windows and macOS binaries on macOS; include separate targets for macOS Intel and Apple Silicon. Follow Tauri's target-triple naming convention. Pin download versions and verify hashes in the future build scripts.

See [Tauri sidecars](https://v2.tauri.app/develop/sidecar/).
